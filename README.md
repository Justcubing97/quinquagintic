# What is Quinquagintic?
Quinquagintic is my first real incremental game. There exists three planned Domains: Decimal, Integer, and Infinity. Each one is focused on a different type of progression:

Decimal: Simple mechanics, one for each reset layer, 10 reset layers

Integer: Intricate reset layers, often having more than one mechanic (almost like IMR's reset layers), 4+ reset layers

Infinity: Mechanics and progression are confusing, only a few reset layers

That's about it for this README!
