## SOME NOTES
### Placeholder numbers
I usually use the percent symbol (%) for placeholder numbers. You can see this in the top bar.
### Version notation
Take 0.1.2.1, which is the current version as of writing.
0.%.%.% - increments when a new Domain is added (new content expansion)
%.1.%.% - increments when a new reset layer is added (small content expansion)
%.%.2.% - increments when some new content is added, but not a whole reset layer (tiny content expansion)
%.%.%.1 - increments when a minor fix is made (no new content)
