# Starter Page

This repository contains a minimal starter page with HTML, CSS, and JavaScript.

Files created:
- `index.html` — The HTML entry.
- `css/styles.css` — Basic styles, variables, and light/dark theming.
- `js/main.js` — Theme toggle, localStorage persistence, and a small form handler.

How to open
1. Open `index.html` in your browser (double-click or open via your editor).

Optional (PowerShell):

```powershell
Start-Process .\index.html
```

Notes
- Theme is persisted in localStorage under key `site-theme`.
- This is a small starting point; feel free to expand components, add build tooling, or integrate frameworks.
